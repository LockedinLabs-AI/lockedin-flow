# Support

Use GitHub Discussions or Issues for reproducible community questions and bugs.
Include the operating system and version, app version, expected behavior, actual behavior, and
content-free diagnostic metadata. Do not attach recordings, transcripts,
credentials, customer data, or protected health information.

Security reports must follow [SECURITY.md](SECURITY.md).

## Platform availability

The native macOS app and Windows/Linux desktop port have separate installation
and validation requirements. See [Mac release status](docs/validation.md) and
the [desktop platform matrix](desktop/README.md#installation-targets) before
planning a deployment. Source availability is not a signed installer release.
There is no supported iOS, iPadOS, or Android application. The npm commands in
this repository are developer build tools, not a published cross-platform
one-command installer.

Community support is best-effort. Organizations that need deployment planning,
managed updates, compatibility commitments, or enterprise maintenance can
contact [LockedIn Labs](https://lockedinlabs.ai/contact/).
